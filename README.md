# 跨国临床试验随机分组和揭盲控制台

源提示词摘要：研究中心按分层因素生成随机分组；药品管理员只见发药信息，研究角色正常情况下不可见治疗组；重复受试者和编号冲突被阻止；紧急揭盲需填写原因并形成不可删除审计记录，断网提交进入待处理队列。

## 技术栈

Nuxt 3、TypeScript、Element Plus、Pinia、Nuxt 路由、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62028`

## 可用流程

- 入组：机构、分层因素和受试者编号校验后生成分层区组随机号与治疗组，目标中心分层名额已满会被拒绝。
- 防重复：相同身份标识或研究中心编号会拒绝再次入组。
- 角色隔离：研究者、药品管理员和监察员看到不同的分组隐藏规则。
- 安全审计：紧急揭盲要求原因，添加后只能追加，不能删除或改写。
- 离线队列：模拟离线提交进入待提交队列，联网后由授权人员确认入库。
- 转中心：选择目标中心与生效日，目标分层名额不足即拒绝；迁移记录预占名额，两个中心同时提交仅一方成功；生效后随机号、治疗组与既往审计不变，旧中心未入库的入组/揭盲申请失效并需重新确认；写入失败可按迁移编号幂等重试，名额不重复占用，页面展示状态与阻塞原因。
